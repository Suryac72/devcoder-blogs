### NumPy

**NumPy (Numerical Python)** is the fundamental package for scientific computing in Python. It provides support for large, multi-dimensional arrays and matrices, along with mathematical functions to operate on these arrays efficiently.

**Why NumPy?**
- **Speed**: 10-100x faster than Python lists due to C implementation
- **Memory Efficiency**: Uses less memory than Python lists
- **Vectorization**: Perform operations on entire arrays without loops
- **Broadcasting**: Automatic element-wise operations on arrays of different shapes

**Key Concepts**:

**Arrays (ndarray)**: Multi-dimensional, homogeneous data structures that store elements of the same type.

**Array Creation**: Multiple methods including `array()`, `zeros()`, `ones()`, `arange()`, `linspace()`, `random` functions.

**Array Operations**: Element-wise arithmetic, matrix operations, broadcasting, slicing, and indexing.

**Linear Algebra**: Matrix multiplication, inverse, determinant, eigenvalues, solving equations.

**Statistical Functions**: Mean, median, standard deviation, variance, percentiles.

**Universal Functions (ufuncs)**: Fast element-wise operations like `sqrt()`, `exp()`, `sin()`, `log()`.

**Use Cases**: Scientific computing, data analysis, machine learning, image processing, signal processing

```python
import numpy as np

# Array creation
arr1 = np.array([1, 2, 3, 4, 5])
arr2 = np.zeros((3, 3))

randint_arr = np.random.randint(0, 10, (3, 3))

# Set random seed
np.random.seed(42)

# Array operations

b = np.array([4, 5, 6])

sum_arr = a + b
difference = a - b
product = a * b
division = a / b
power = a ** 2
dot_product = np.dot(a, b)

# Universal functions (ufuncs)
arr = np.array([1, 2, 3, 4])
print(np.sqrt(arr))
print(np.exp(arr))
print(np.log(arr))
print(np.sin(arr))

# Matrix operations
matrix1 = np.array([[1, 2], [3, 4]])
matrix2 = np.array([[5, 6], [7, 8]])

# Matrix multiplication
matmul = np.matmul(matrix1, matrix2)
# or use @ operator
matmul = matrix1 @ matrix2

transpose = matrix1.T
inverse = np.linalg.inv(matrix1)
determinant = np.linalg.det(matrix1)
eigenvalues, eigenvectors = np.linalg.eig(matrix1)

# Solve linear equations: Ax = b
A = np.array([[3, 1], [1, 2]])
b = np.array([9, 8])
x = np.linalg.solve(A, b)

# Statistical operations
data = np.random.randn(1000)
mean = np.mean(data)
std = np.std(data)
var = np.var(data)
median = np.median(data)
percentile_75 = np.percentile(data, 75)
min_val = np.min(data)
max_val = np.max(data)

# Multi-dimensional statistics
matrix = np.random.randn(3, 4)
col_means = np.mean(matrix, axis=0)
row_means = np.mean(matrix, axis=1)

# Reshaping and slicing
arr = np.arange(12)
reshaped = arr.reshape(3, 4)
flattened = reshaped.flatten()
raveled = reshaped.ravel()

# Slicing
matrix = np.arange(20).reshape(4, 5)
print(matrix[0, :])  # First row
print(matrix[:, 0])  # First column
print(matrix[1:3, 2:4])  # Submatrix

# Boolean indexing
arr = np.arange(10)
mask = arr > 5
filtered = arr[mask]

# Fancy indexing
arr = np.arange(20)
indices = [1, 3, 7, 15]
selected = arr[indices]

# Broadcasting
a = np.array([[1, 2, 3], [4, 5, 6]])
b = np.array([10, 20, 30])
result = a + b  # b is broadcast

# Concatenation and stacking
a = np.array([[1, 2], [3, 4]])
b = np.array([[5, 6], [7, 8]])

concatenated = np.concatenate([a, b], axis=0)
vstacked = np.vstack([a, b])
hstacked = np.hstack([a, b])
dstacked = np.dstack([a, b])

# Splitting
arr = np.arange(16).reshape(4, 4)
split = np.split(arr, 2, axis=0)
vsplit = np.vsplit(arr, 2)
hsplit = np.hsplit(arr, 2)

# Copying
arr = np.array([1, 2, 3])
view = arr.view()  # Creates a view
copy = arr.copy()  # Creates a copy

# Where function
arr = np.array([1, 2, 3, 4, 5])
result = np.where(arr > 2, arr, 0)

# Unique values
arr = np.array([1, 2, 2, 3, 3, 3, 4])
unique = np.unique(arr)
unique, counts = np.unique(arr, return_counts=True)

# Sorting
arr = np.array([3, 1, 4, 1, 5, 9, 2, 6])
sorted_arr = np.sort(arr)

# Saving and loading
arr = np.array([1, 2, 3, 4, 5])

# Save multiple arrays

```

### Pandas

**Pandas** is a powerful data manipulation and analysis library. It provides easy-to-use data structures (DataFrame and Series) for working with structured data.

**Core Data Structures**:

**Series**: One-dimensional labeled array, like a column in a spreadsheet.

**DataFrame**: Two-dimensional labeled data structure with columns of potentially different types, like a spreadsheet or SQL table.

**Key Features**:

**Data Import/Export**: Read from and write to CSV, Excel, JSON, SQL databases, and many other formats.

**Data Selection**: Multiple ways to access data using labels (`.loc`) or positions (`.iloc`).

**Data Cleaning**: Handle missing values with `fillna()`, `dropna()`, `interpolate()`.

**Data Transformation**:
- **Sorting**: Organize by values or index
- **Filtering**: Select rows based on conditions
- **Grouping**: Split-apply-combine operations with `groupby()`
- **Merging**: Combine datasets using `merge()`, `join()`, `concat()`

**Aggregation**: Calculate statistics (mean, sum, count) on groups of data.

**Time Series**: Specialized functionality for date/time data including resampling, rolling windows, time shifts.

**Pivot Tables**: Create Excel-style pivot tables for data summarization.

**Apply Functions**: Apply custom functions to rows, columns, or entire DataFrames.

**Use Cases**: Data cleaning, exploratory data analysis, financial analysis, statistical analysis, data preparation for ML

### Matplotlib

**Matplotlib** is the foundational plotting library in Python. It provides a MATLAB-like interface for creating static, animated, and interactive visualizations.

**Key Components**:

**Figure**: The entire window or page where plots appear.

**Axes**: The area where data is plotted (can have multiple axes in one figure).

**Plot Types**:
- **Line plots**: Show trends over continuous data
- **Scatter plots**: Show relationships between two variables
- **Bar plots**: Compare categorical data
- **Histograms**: Show distribution of continuous data
- **Box plots**: Show statistical distribution with quartiles
- **Pie charts**: Show proportions of a whole
- **Heatmaps**: Visualize matrix data with colors
- **Contour plots**: Show 3D data in 2D with contour lines
- **3D plots**: Visualize three-dimensional data

**Customization**:
- Colors, line styles, markers
- Labels, titles, legends
- Grid lines, spines
- Font sizes and styles
- Figure size and DPI

**Subplots**: Create multiple plots in a single figure using `subplots()`.

**Styles**: Pre-defined style sheets for consistent aesthetics.

**Use Cases**: Data exploration, scientific publications, presentations, reports, dashboards

### Seaborn

**Seaborn** is a statistical visualization library built on top of Matplotlib. It provides a high-level interface for creating attractive and informative statistical graphics with less code.

**Why Seaborn?**
- **Better default aesthetics**: More attractive plots out of the box
- **Statistical functions**: Built-in support for visualizing distributions and relationships
- **Easier syntax**: Less code for complex visualizations
- **Integration**: Works seamlessly with Pandas DataFrames

**Plot Categories**:

**Distribution Plots**: Visualize single or multiple distributions
- `histplot()`: Histograms with KDE
- `kdeplot()`: Kernel density estimates
- `boxplot()`: Box-and-whisker plots
- `violinplot()`: Combination of box plot and KDE

**Categorical Plots**: Visualize categorical data
- `barplot()`: Bar charts with error bars
- `countplot()`: Count of observations

## Deep Learning Libraries

### TensorFlow and Keras

**TensorFlow** is an end-to-end open-source platform for machine learning developed by Google. **Keras** is a high-level neural networks API that runs on top of TensorFlow, making deep learning more accessible.

**Key Concepts**:

**Tensors**: Multi-dimensional arrays (generalization of matrices) that flow through the network - hence "TensorFlow".

**Neural Networks**: Computing systems inspired by biological neural networks, consisting of interconnected nodes (neurons) organized in layers.

**Layers**: Building blocks of neural networks:
- **Dense (Fully Connected)**: Every neuron connects to every neuron in next layer
- **Convolutional (Conv2D)**: Extract spatial features from images
- **Pooling**: Reduce spatial dimensions (MaxPooling, AveragePooling)
- **Dropout**: Randomly deactivate neurons to prevent overfitting
- **Recurrent (LSTM, GRU)**: Process sequential data
- **Embedding**: Convert categorical data to dense vectors

**Model Building Approaches**:
- **Sequential API**: Stack layers linearly (simplest)
- **Functional API**: Create complex architectures with multiple inputs/outputs
- **Subclassing**: Maximum flexibility for custom models

**Training Process**:
1. **Compile**: Specify optimizer, loss function, metrics
2. **Fit**: Train the model on data
3. **Evaluate**: Test model performance
4. **Predict**: Make predictions on new data

**Optimizers**: Algorithms that update model weights:
- Adam, SGD, RMSprop, Adagrad

**Loss Functions**: Measure how wrong predictions are:
- Binary/Categorical Crossentropy (classification)
- MSE, MAE (regression)

**Callbacks**: Functions called during training:
- **EarlyStopping**: Stop when performance stops improving
- **ModelCheckpoint**: Save best model during training
- **TensorBoard**: Visualize training progress

**Transfer Learning**: Use pre-trained models (VGG, ResNet, Inception) and adapt them to your task.

**Use Cases**: Image classification, object detection, natural language processing, time series prediction, generative models

# Custom layers
class CustomLayer(layers.Layer):
    def __init__(self, units=32):
        super(CustomLayer, self).__init__()
        self.units = units
    
    def build(self, input_shape):
        self.w = self.add_weight(
            shape=(input_shape[-1], self.units),
            initializer='random_normal',
            trainable=True
        )
        self.b = self.add_weight(
            shape=(self.units,),
            initializer='zeros',
            trainable=True
        )
    
    def call(self, inputs):
        return tf.matmul(inputs, self.w) + self.b

# Custom training loop

loss_fn = keras.losses.SparseCategoricalCrossentropy()

@tf.function
def train_step(x, y):
    with tf.GradientTape() as tape:
        predictions = model(x, training=True)

### PyTorch

**PyTorch** is an open-source deep learning framework developed by Facebook/Meta. It's known for its flexibility, dynamic computation graphs, and Pythonic approach, making it popular in research.

**Key Differences from TensorFlow**:
- **Dynamic Computation Graph**: Build graphs on-the-fly (eager execution)
- **More Pythonic**: Feels more like native Python
- **Easier Debugging**: Standard Python debugging tools work
- **Research-Friendly**: Preferred in academic settings

**Core Concepts**:

**Tensors**: Similar to NumPy arrays but can run on GPUs for faster computation. Support automatic differentiation.

**Autograd**: Automatic differentiation system that computes gradients automatically during backpropagation.

**nn.Module**: Base class for all neural network modules. You inherit from this to create custom models.

**Model Architecture**:
```
Define model → Define loss → Define optimizer → Training loop
```

**Common Layers**:
- **nn.Linear**: Fully connected layer
- **nn.Conv2d**: 2D convolutional layer
- **nn.MaxPool2d**: Max pooling
- **nn.ReLU, nn.Sigmoid**: Activation functions
- **nn.LSTM, nn.GRU**: Recurrent layers
- **nn.Dropout**: Regularization
- **nn.BatchNorm2d**: Batch normalization

**DataLoader**: Efficiently load data in batches with multiprocessing support.

**Custom Training Loop**: Unlike Keras, you write the training loop explicitly:
1. Forward pass: Get predictions
2. Calculate loss
3. Backward pass: Compute gradients with `loss.backward()`
4. Update weights: `optimizer.step()`

**GPU Support**: Easy device management with `.to(device)` or `.cuda()`.

**Saving Models**:
- **state_dict**: Save just the parameters (recommended)
- **Entire model**: Save architecture and parameters

**TorchVision**: Computer vision utilities including pre-trained models and data augmentation.

**Use Cases**: Research, computer vision, NLP, reinforcement learning, GANs, custom architectures
