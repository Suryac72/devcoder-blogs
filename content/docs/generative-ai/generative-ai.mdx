### OpenAI

**OpenAI** provides powerful AI models through a simple API, including GPT models for text generation, DALL-E for image generation, and Whisper for speech recognition.

**Key Features**:
- **Chat Completions**: Generate conversational responses using GPT models
- **Streaming**: Receive responses in real-time as they're generated
- **Function Calling**: Allow models to call external functions/APIs
- **Image Generation (DALL-E)**: Create images from text descriptions
- **Embeddings**: Convert text into numerical vectors for similarity search
- **Vision**: Analyze and describe images
- **Audio (Whisper)**: Transcribe and translate audio
- **Text-to-Speech**: Convert text into natural-sounding speech
- **Fine-tuning**: Customize models for specific tasks

**Use Cases**: Chatbots, content generation, code assistance, image creation, data analysis, translation

### Anthropic Claude

**Anthropic Claude** is an AI assistant known for being helpful, harmless, and honest. It excels at long-context understanding and complex reasoning tasks.

**Key Features**:
- **Messages API**: Create conversational interactions with Claude
- **Long Context**: Handle up to 200K tokens of context
- **Vision**: Analyze images and documents
- **Streaming**: Real-time response generation
- **System Prompts**: Set behavioral guidelines for Claude
- **Multi-turn Conversations**: Maintain conversation history

**Model Tiers**:
- **Claude Sonnet**: Balance of intelligence and speed
- **Claude Opus**: Maximum intelligence for complex tasks
- **Claude Haiku**: Fast and cost-effective

**Use Cases**: Document analysis, coding assistance, research, creative writing, complex reasoning tasks

### LangChain

**LangChain** is a framework for developing applications powered by language models. It provides tools to chain together LLM calls, manage context, and build complex AI workflows.

**Core Components**:

**Chains**: Sequence multiple LLM calls or operations together. Types include:
- **LLMChain**: Basic chain linking prompt and LLM
- **SequentialChain**: Chain outputs become inputs for next chain
- **RouterChain**: Dynamically route to different chains based on input

**Prompts**: Templates for structuring input to language models with variables and formatting.

**Memory**: Store and retrieve conversation history to maintain context across interactions.

**Agents**: AI systems that use LLMs to decide which actions to take and in what order. They can use tools like calculators, search engines, or APIs.

**Document Loaders**: Import data from various sources (PDFs, websites, databases).

**Text Splitters**: Break large documents into chunks for processing.

**Vector Stores**: Store and retrieve document embeddings for semantic search (FAISS, Chroma, Pinecone).

**Embeddings**: Convert text to numerical vectors for similarity comparisons.

**Use Cases**: Chatbots, question-answering systems, document analysis, automated research, data extraction

### Hugging Face Transformers

**Hugging Face Transformers** is the leading library for state-of-the-art Natural Language Processing (NLP) and computer vision models. It provides thousands of pre-trained models that you can use immediately or fine-tune for your specific needs.

**Key Concepts**:

**Pipelines**: High-level API for common NLP tasks. Simply specify the task and model, and the pipeline handles tokenization, model inference, and post-processing automatically.

**Common Tasks**:
- **Text Generation**: Continue or complete text
- **Text Classification**: Categorize text (sentiment analysis, topic classification)
- **Question Answering**: Extract answers from context
- **Named Entity Recognition (NER)**: Identify entities like names, locations, organizations
- **Translation**: Translate between languages
- **Summarization**: Condense long text into summaries
- **Fill Mask**: Predict missing words
- **Zero-Shot Classification**: Classify without training examples

**Tokenizers**: Convert text into numbers (tokens) that models can process. Handle special tokens, padding, and truncation.

**Models**: Pre-trained neural networks (BERT, GPT, T5, etc.) that you can use directly or fine-tune on your data.

**Fine-tuning**: Adapt pre-trained models to your specific task with your own dataset using the Trainer API.

**Use Cases**: Chatbots, sentiment analysis, content moderation, document classification, translation services, text summarization

### LlamaIndex

**LlamaIndex** (formerly GPT Index) is a data framework for building LLM-powered applications. It specializes in connecting custom data sources to large language models, enabling retrieval-augmented generation (RAG).

**Core Concepts**:

**Indexes**: Data structures that organize your documents for efficient retrieval:
- **VectorStoreIndex**: Uses embeddings for semantic search
- **KnowledgeGraphIndex**: Structures data as a graph
- **TreeIndex**: Hierarchical document structure

**Document Loaders**: Import data from various sources (text files, PDFs, websites, databases).

**Query Engines**: Interface for asking questions about your indexed data. They retrieve relevant information and synthesize answers.

**Chat Engines**: Maintain conversation history for multi-turn interactions with your data.

**Retrievers**: Find relevant documents or passages based on queries.

**Service Context**: Configuration for LLMs, embeddings, and other settings.

**Storage**: Persist indexes to disk and reload them later.

**Key Features**:
- **RAG (Retrieval-Augmented Generation)**: Combine document retrieval with LLM generation
- **Multi-document queries**: Search across multiple document collections
- **Metadata filtering**: Filter documents by attributes
- **Response synthesis**: Multiple strategies for combining retrieved information

**Use Cases**: Question answering over documents, chatbots with knowledge bases, research assistants, documentation search, customer support systems
